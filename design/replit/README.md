# Pacote Replit

`autotrader-meridian-replit.zip` contém o protótipo estático completo (`index.html`, `assets/`) e um `.replit` que serve a pasta na porta 8080.

**Como usar**

1. Crie um Repl do tipo *Static* (ou *HTTP Server*) e importe o conteúdo do zip.
2. Rode: `python3 -m http.server 8080 --bind 0.0.0.0`.
3. Abra a URL pública — a navegação por hash funciona sem build.

O zip não inclui as capturas (`prototype/shots`) nem o arquivo FigCraft: são materiais de revisão, não parte do site.
